## Limitations

This is one model, one run, and a regex-based first gate. The baseline was already strong on several modern Roblox patterns. A pass does not prove Luau type correctness, runtime behavior, policy compliance, or backend semantics. Some failures can reflect missing explicit wording rather than unsafe code. Critical answers still need human review and controlled Roblox integration tests.

Future reports should repeat the paired protocol across supported agents/models, add emitted-code static analysis, and report variance rather than treating this run as a universal causal estimate.
