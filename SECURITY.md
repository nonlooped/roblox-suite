# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose credentials, enable abuse, or put live Roblox experiences at risk. Use GitHub's **Report a vulnerability** private advisory flow for this repository:

https://github.com/nonlooped/roblox-suite/security/advisories/new

Include the affected skill or script, impact, reproduction details, and the relevant official Roblox source. You should receive an acknowledgement within 7 days. No fix timeline is promised until impact is understood.

Incorrect guidance without an exploitable disclosure should use the public **Report an inaccuracy** issue form instead.

## Scope

The `scripts/` directories contain maturity-labeled examples, not a versioned production library. Security reports are still welcome when an example could cause unsafe agent output, duplicated purchases, data loss, credential exposure, or an authority-boundary bypass.
